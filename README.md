# 📸 Wedding Photography

A responsive website for a professional wedding photographer, developed as a **team project**.

The website presents photography services, portfolio works, client testimonials, frequently asked questions, and a contact form for booking a photography session.

🔗 **Live Demo:** [https://serhii-onykiienko.github.io/project-java-script-team-03/](https://serhii-onykiienko.github.io/project-java-script-team-03/)

---

## ✨ Features

- Responsive and adaptive layout
- Mobile navigation menu
- About and services sections
- Client testimonials
- Interactive portfolio section
- Portfolio filtering and additional content loading
- FAQ accordion
- Contact form
- Success modal after form submission
- Interactive sliders
- Smooth navigation between sections

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Serhii-Onykiienko/project-java-script-team-03.git
```

### 2. Navigate to the project directory

```bash
cd project-java-script-team-03
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

---

## 📜 Available Scripts

### Development

```bash
npm run dev
```

Starts the Vite development server.

### Build

```bash
npm run build
```

Creates a production build.

### Preview

```bash
npm run preview
```

Previews the production build locally.
